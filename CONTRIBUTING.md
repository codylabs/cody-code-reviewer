# Contributing

Focused bug fixes, tests, documentation corrections, and review-quality improvements are
welcome.

1. Open an issue before starting a large or behavior-changing contribution.
2. Create a branch from `master`.
3. Install the hashed development dependencies.
4. Run `python -m pytest -m "not integration"`.
5. Keep pull requests narrow and describe the user-visible effect.

Do not include API keys, repository tokens, customer code, or model responses containing
private code in issues, fixtures, screenshots, or commits.

By contributing, you agree that your contribution may be distributed under this
repository's existing licence. The project is source-available rather than OSI open
source; see [LICENSE.md](LICENSE.md).
